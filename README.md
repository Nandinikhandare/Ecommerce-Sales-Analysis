# E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using SQL, Microsoft Excel, and Power BI to understand business performance and identify meaningful insights.

## Tools & Technologies
- SQL – Data querying and analysis
- Microsoft Excel – Data cleaning and analysis
- Power BI – Interactive dashboard and data visualization

## Key Activities
- Analyzed sales and profit performance.
- Performed customer and product analysis.
- Evaluated regional sales trends.
- Created 10+ SQL queries to extract business insights.
- Developed an interactive Power BI dashboard.
- Used Excel for data processing and analysis.

## Key Skills
SQL, Excel, Power BI, Data Analysis, Data Visualization, Business Intelligence, Data Cleaning.

## Project Objective
To transform raw e-commerce data into meaningful insights that support business decision-making.
